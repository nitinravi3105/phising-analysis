# Manual Testing Deliverables

Open `test_scenarios.csv`, `test_cases.csv`, and `defect_report_template.csv` in Excel or Google Sheets.

For each test case:
1. Set up the preconditions.
2. Execute the steps manually.
3. Record the actual result.
4. Mark Pass or Fail.
5. If it fails, create a defect with reproduction steps, severity, priority, and screenshot.
6. After a fix, retest and run regression cases.

Do not mark tests as passed until you have actually executed them against the running app.
